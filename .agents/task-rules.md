# Task Execution Rules

Before implementing any task:

1. Read relevant documentation.
2. Identify affected domain.
3. Create implementation plan.
4. Create tests first when possible.

For every completed feature provide:

## Summary

What was built.

## Files Created

List all new files.

## Files Modified

List all changed files.

## Database Changes

Migrations created.

## Tests

Unit tests added.

Feature tests added.

## Security Review

Potential security impacts.

## Performance Review

Potential performance impacts.

## Acceptance Checklist

- [ ] Code Complete
- [ ] Tests Pass
- [ ] Security Checked
- [ ] Documentation Updated

Never mark task complete if checklist is incomplete.
